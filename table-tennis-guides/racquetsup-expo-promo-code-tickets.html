Pong Home is an official partner of RacquetsUp Expo 2027 and offers a promo code for 10% off every ticket type. This page covers the code, how to use it, and the current price for every pass, including the day pass, weekend pass, junior pass, group pass, and VIP pass.

RacquetsUp Expo 2027 runs February 19 to 21 at the Enercare Centre in Toronto, featuring tennis, table tennis, pickleball, padel, squash, and badminton. For the full event details, see the RacquetsUp Expo partnership guide.

How to use the RacquetsUp Expo promo code

  1. Go to the official RacquetsUp Expo 2027 ticket page on Eventbrite.
  2. Select the pass you want: single-day, full weekend, junior, group, or VIP.
  3. At checkout, look for the promo code or discount code field.
  4. Enter PONGHOMETEN and apply it before completing payment.
  5. Confirm the 10% discount is reflected in your order total before checking out.
Ticket vs pass. RacquetsUp Expo uses the terms ticket and pass interchangeably. A single-day ticket and a single-day pass are the same product, and the promo code applies to both regardless of which term is shown at checkout.

RacquetsUp Expo kids and junior tickets

Families attending with kids can use the Junior's Weekend Pass, priced at 25 CAD before the promo code. It covers full weekend access for players under 14 and includes the Junior Racquets Discovery program, which lets kids ages 5 to 17 try tennis, pickleball, table tennis, padel, squash, and badminton with instructors on site. The PONGHOMETEN promo code applies to junior tickets the same way it applies to adult tickets.

Is the RacquetsUp Expo discount code still valid

Pong Home's PONGHOMETEN promo code is active for RacquetsUp Expo 2027 and applies to tickets purchased ahead of the February 19 to 21 event dates. If the code does not apply at checkout, confirm it is entered exactly as shown, with no spaces, and that it is entered in the promo code or discount code field on the Eventbrite checkout page rather than a general search box.
