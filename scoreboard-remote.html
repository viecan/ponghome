Table Tennis Scoreboard Remote for Apple Watch

Pong Home's scoreboard remote is a tap to score tool built for Apple Watch and other small screens. It has three buttons: tap Player 1's name to add a point for Player 1, tap Player 2's name to add a point for Player 2, and tap Undo to remove the last point if you scored by mistake. Scores and player names are saved on the device, so the game keeps its state between taps without needing a network connection.

How the scoreboard remote works

Rename each player by tapping the small pencil icon next to their name. The rest of each half of the screen is one large button for speed during fast rallies. A small reset link in the corner clears the game back to zero to zero.
